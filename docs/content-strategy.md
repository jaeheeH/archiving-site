# ARCH-B 작품 아카이브 기획안

이 문서는 아트 영역의 세부 기획이다. 아트·참고사이트·블로그를 포함한 전체 범위는 [프로젝트 기획안](project-plan.md)을 기준으로 한다.

수정일: 2026-09-07

사용자의 “데일리아트처럼 작품들을 모으고 싶어”라는 방향에 따라 기존 기획을 대체한다. 중심 콘텐츠는 미술 작품이다. 후속 작업에서 실제 작품 30점의 이미지와 정보를 수집하고 레퍼런스 사이트를 조사했다. [수집 결과](../research/art-collection/README.md)와 [레퍼런스 조사](../research/art-collection/reference-sites.md)를 함께 참고한다. 기존 사이트에 작품을 등록하거나 공개하는 작업은 아직 진행하지 않았다.

## 1. 서비스의 중심

**작품을 모으고, 이야기를 읽고, 마음에 드는 작품으로 나만의 컬렉션을 만드는 온라인 미술 아카이브.**

소개 문구 제안: “하루 한 작품, 좋아하는 예술이 쌓이는 곳.”

전문 지식이 없어도 이미지를 보며 취향을 발견할 수 있도록 한다. 작품 감상이 첫 경험이며, 작품의 이야기와 작가·시대 정보는 관심을 넓혀주는 역할이다.

DailyArt는 작품과 짧은 이야기, 작가 및 미술관 정보, 주제별 컬렉션을 연결한다. 이 구조를 핵심 참고로 삼는다. 29Magazine은 테마를 붙이는 방식과 정기적으로 읽을 수 있는 편집 코너에 보조적으로 참고한다. [DailyArt 공식 소개](https://www.getdailyart.com/) · [29Magazine](https://www.29cm.co.kr/content/29magazine)

## 2. 가장 중요한 콘텐츠 단위: 작품 한 점

작품마다 하나의 상세 페이지를 갖는다. 오늘의 작품, 작가 목록, 주제별 컬렉션은 이 작품 페이지에 연결한다. 같은 작품을 여러 곳에서 소개해도 작품 정보와 저장 상태는 한 번만 관리한다.

| 정보 | 내용 |
| --- | --- |
| 작품 이미지 | 전체 모습을 원래 비율로 감상하고 확대할 수 있는 이미지 |
| 작품명 | 한국어 표기와 원문 제목 |
| 작가 | 이름과 작가별 작품 모아보기; 미상·공동 제작 등 원자료 표기 보존 |
| 제작 시기 | 정확한 연도 또는 원출처의 추정 연대와 범위 |
| 작품 정보 | 재료·기법, 크기, 소장처, 확인 가능한 사조·시대 |
| 짧은 이야기 | 선별 작품에 400~800자 안팎의 이야기 추가; 기본 아카이브 공개의 필수 조건은 아님 |
| 감상 포인트 | 선별 작품에 이미지에서 찾아볼 디테일 1~3개 추가 |
| 연결 | 같은 작가의 작품, 같은 주제를 담은 작품 |
| 출처 | 공식 작품 페이지, 소장품 식별번호, 이미지 제공처와 사용 조건 |

기본 정보가 알려지지 않았으면 추정해서 채우지 않는다. 작품의 역사적 정보와 편집자의 감상은 구분한다. 작품 설명은 공식 자료를 바탕으로 직접 작성하며 DailyArt의 해설을 수집 대상으로 삼지 않는다.

## 3. 사이트 구성

| 메뉴 | 핵심 경험 |
| --- | --- |
| 오늘의 작품 | 선정한 작품 한 점과 짧은 이야기 감상 |
| 작품 둘러보기 | 전체 작품을 이미지 중심으로 탐색하고 검색 |
| 컬렉션 | 주제나 분위기로 묶은 작은 전시 감상 |
| 나의 컬렉션 | 마음에 드는 작품을 저장하고 다시 감상 |

작가별 정리는 첫 수집 단계부터 제공한다. 현재 검토 페이지에는 확인된 작가 19명의 이름과 작품 수, 작가별 필터, 작품 카드의 작가 연결을 추가했다. 작가 미상 4점은 별도 분류하며 한 명의 작가로 취급하지 않는다. 미술관마다 달랐던 동일 작가의 표기는 원자료의 작가 식별번호와 대조해 통합하고, 원래 표기도 함께 보존한다. [작가별 목록](../research/art-collection/artists.md)을 참고한다.

주요 동선: 오늘의 작품 → 작품 확대 감상 → 이야기 읽기 → 저장 → 같은 작가나 주제의 다른 작품.

홈에서는 오늘의 작품을 먼저 소개하고, 테마 컬렉션과 최근 추가된 작품을 이어 보여준다. 새로 수집한 날짜, 작품 제작 시기, 오늘의 추천 날짜는 구분한다.

## 4. 수집할 작품 범위

초기에는 회화와 판화를 중심으로 시작하는 안을 제안한다. 이는 아직 확정되지 않은 수집 범위이며, 이후 드로잉·조각·공예·사진 등으로 넓힐 수 있다.

유명 작품으로 친숙한 진입점을 만들고, 덜 알려진 작가나 다른 지역의 작품도 함께 배치한다. 작가의 명성만으로 선정하지 않고 이미지 품질, 설명 근거, 감상할 디테일을 기준으로 고른다.

공식 미술관 자료 중 이미지 사용 범위가 확인되는 작품부터 수집한다. The Met은 Open Access 작품 이미지와 기본 데이터를 CC0로 제공하며 공식 컬렉션에서 OA 표시로 확인할 수 있다. [The Met Open Access](https://www.metmuseum.org/hubs/open-access)

자료를 가져올 때의 순서:

1. 공식 소장품 페이지에서 작품 후보를 찾는다.
2. 작품명·작가·연대·재료·소장처·식별번호를 기록한다.
3. 해당 이미지의 공개 이용 조건과 원본 품질을 확인한다.
4. 한국어 제목과 짧은 해설을 편집한다.
5. 작가와 주제를 연결하고 검토 후 공개한다.

기관 전체의 공개 정책만으로 모든 이미지를 사용 가능하다고 처리하지 않는다. 개별 작품의 표시를 함께 기록한다. 여러 미술관에 유사 제목이나 같은 판화의 다른 인쇄본이 있을 수 있으므로 제목만으로 작품을 합치지 않는다.

## 5. 분류 체계

| 축 | 예시 | 성격 |
| --- | --- | --- |
| 작가 | 작가별 이름 | 공식 자료 기반 |
| 제작 시기 | 연도 또는 시기 범위 | 공식 자료 기반 |
| 유형 | 회화·판화·드로잉·조각 | 공식 자료 기반 |
| 사조 | 인상주의 등 확인 가능한 분류 | 근거가 있을 때만 부여 |
| 주제 | 인물·풍경·꽃·동물·실내·일상 | 작품 내용에 따른 편집 분류 |
| 분위기 | 고요한·따뜻한·몽환적인 | 편집자의 감상에 따른 분류 |

작품명·작가·별칭 검색과 작가·시기·유형·소장처·이미지 유무 필터를 기본으로 제공한다. 많은 작품과 작가를 찾을 수 있도록 페이지를 분할하고 이름 색인을 제공한다. 분위기는 주제별 컬렉션에서 활용한다.

## 6. 테마 컬렉션 예시

- **창가에 머무는 시간**: 창문과 실내, 빛이 등장하는 작품.
- **그림 속 작은 정원**: 꽃과 식물을 다룬 작품.
- **해가 진 뒤의 풍경**: 밤과 저녁의 색을 비교하는 작품.
- **동물과 함께한 장면**: 일상 속 동물이 등장하는 작품.
- **한 작가의 여러 얼굴**: 같은 작가의 서로 다른 시기나 소재를 함께 감상.

각 컬렉션은 5~8점을 기준으로 시작하고, 한 작품을 여러 컬렉션에 연결할 수 있게 한다. 컬렉션에는 짧은 전시 소개와 작품별 선정 이유를 붙인다. 위 제목은 기획 예시이며 실제 작품 선정은 아직 하지 않았다.

## 7. 첫 공개 분량과 수집 운영

현재 30점은 검증 표본이다. **1,000점 시험 수집 → 첫 공개 약 5,000점 → 10,000점 이상 지속 확장**을 규모 제안으로 삼는다. 확보 가능한 자료와 운영량을 검증해 조정하며 아직 달성한 수량은 아니다.

작품의 기본 정보·이미지 제공 상태·출처·작가 연결을 먼저 정리하고 짧은 해설은 선별 작품에 추가한다. 초기 작가 100명 이상과 우선 작가 20명의 자료 확보 깊이를 목표로 조사하되, 실제 존재하고 이용 가능한 범위를 넘어 수량을 강제하지 않는다. 컬렉션과 오늘의 소개는 이미 등록된 작품에 연결한다.

준비 순서:

1. 현재 30점으로 작가·작품 식별과 원자료·이미지 보존 기준을 확정한다.
2. 기관별 일괄 수집과 재실행·오류 처리·변경 이력을 구현한다.
3. 1,000점으로 수집량·저장량·예외 검토량·대량 검색을 확인한다.
4. 우선 작가의 자료를 보완하면서 5,000점 수준으로 확대하고, 선별 작품을 해설과 컬렉션으로 소개한다.

수집은 기관별 배치와 변경분 반영으로 운영하고 해설은 별도 편집 주기를 따른다. 원자료·이미지·수정 이력·백업을 보존한다. 재소개 시 최초 등록일을 유지한다. 상세 수집·보존·품질 기준은 [대규모 작품 아카이브 운영안](art-archive-plan.md)을 따른다.

## 8. 구현 우선순위

1. **수집·보존 기반**: 일괄 수집, 실패 재개, 식별·중복·작가 연결, 원자료·변경 이력·백업.
2. **작가 전용 아카이브**: 이름·별칭·수집 범위, 작품 수와 이미지 확보 수, 시기·소장처별 탐색.
3. **전체 작품 목록·상세**: 페이지 분할, 검색·복합 필터, 이미지 크기별 제공, 출처·갱신일.
4. **저장**: 마음에 드는 작품을 보관하고 다시 열기.
5. **오늘의 작품·에디터 컬렉션**: 수집 자료 중 일부에 설명과 선정 이유 추가.
6. **확장**: 개인 컬렉션 이름 지정, 감상 메모.

완료 기준은 1,000점 시험 운영과 실제 공개 규모에서 ‘수집 → 검증 → 작가 연결 → 공개 → 탐색 → 저장 → 재열람’ 및 자료 복원까지 확인하는 것이다. 현재 30점 검토 페이지와 대량 운영 시스템의 구현 상태는 구분한다.

## 9. 콘텐츠 품질 확인

- 이미지의 전체 구도와 비율이 보이는가?
- 작품명·작가·연대가 원출처와 일치하는가?
- 소장처와 현재 전시 여부를 혼동하지 않는가?
- 해설이 출처 없는 일화나 작가 의도 추정을 포함하지 않는가?
- 저장한 작품을 다시 찾기 쉬운가?
- 주제별 컬렉션의 선정 이유가 납득되는가?

첫 평가에서는 작품 수와 함께 저장 후 재열람, 다른 작품으로의 탐색, 독자가 기억한 감상 포인트를 확인한다.
