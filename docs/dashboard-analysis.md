# ARCH.B 운영 대시보드 분석

2026-10-07 ARCH.B DB의 읽기 전용 점검 결과입니다. 화면은 요청 시 최신 값을 다시 집계합니다.

## 현재 운영에서 먼저 처리할 일

1. **가공 대기 뉴스 148편:** 전체 뉴스 160편 중 12편이 공개 상태입니다. 오늘 등록한 148편을 자료 조사 → 초안 검토 → 저장·발행 순서로 처리할 수 있습니다. 등록과 발행은 다른 날짜·모집단이므로 두 수치를 단순히 나눠 발행 전환율로 표시하지 않았습니다.
2. **기존 발행 뉴스의 품질 확인 12편:** 11편은 본문 분량·섹션·참고자료 보강이 필요하며, 기존에 준비한 보강 초안을 검토할 수 있습니다. Plant Life 기사는 본문 기준은 충족하지만 공식 1차 자료의 확인 표시가 필요합니다. 이 점검으로 기존 기사를 수정하거나 비공개 처리하지 않습니다.
3. **최근 7일 기사 조회 기록 23건:** 기사별 후속 주제를 선정할 때 북마크·좋아요와 함께 확인합니다. 작은 표본이므로 특정 분야의 성장이나 방문자 전환을 단정하지 않습니다.

발행 기사 구성은 디자인 4편·개발 4편·인테리어 4편·에디토리얼 25편입니다. 현재 북마크는 5건, 좋아요는 0건이며 회원 계정은 5개입니다.

## 집계 기준

| 지표 | 기준 |
| --- | --- |
| 뉴스 등록 | 뉴스의 등록일, 선택 기간·한국 시간 기준 |
| 기사 발행 | 현재 공개된 뉴스·에디토리얼의 저장된 발행일 기준 |
| 기간 조회 | 보존된 `post_views` 기록, 기사별 24시간 중복 제외 |
| 누적 조회 | 현재 공개된 전체 기사의 누적 조회 카운터 합계 |
| 북마크·좋아요 | 현재 저장된 누적 값. 취소를 반영하며 기간 내 발생 횟수가 아님 |
| 회원 구성 | 현재 사이트 회원 프로필의 권한별 계정 수. 방문자 수가 아님 |
| 품질 확인 | 기존 발행 검증과 같은 분량·섹션·사실/분석·공식 참고자료 기준 |

기간은 5·7·30일을 제공하며 오늘의 진행 중인 수치를 포함합니다. 직전 기간은 동일한 시각까지 비교합니다. 초기 뉴스에 저장된 발행일은 원문 발행일에서 가져왔으므로 서비스에 처음 게시한 시각과 다를 수 있습니다. 삭제된 조회 기록을 복원하거나 체류 시간·순방문자 수를 추정하지 않습니다.

관리자는 전체 콘텐츠, 부관리자는 관리자 작성 콘텐츠를 제외한 범위, 에디터는 자신의 기사와 반응을 집계합니다. 회원 지표는 관리자·부관리자만 볼 수 있습니다. 조회·회원·품질 조회가 실패하면 집계 불가를 표시합니다.

## 구현과 검증

- 대시보드와 운영 통계는 같은 집계와 화면을 재사용합니다. 통계 화면의 기사 순위는 15편, 대시보드는 5편을 표시합니다.
- 새 DB 테이블·스케줄러·분석 서비스는 추가하지 않았습니다. 정기 뉴스 자동화 설정은 변경하지 않았습니다.
- 한국 날짜 경계, 기간 비교, 미래 날짜 제외, 발행/미발행·작성자 범위, 0/누락 데이터, 익명 접근 차단과 실제 DB 조인 필터를 검사했습니다.
- 실행: `npx tsx --env-file=.env.local scripts/check-dashboard.mjs http://localhost:3000 --live`
