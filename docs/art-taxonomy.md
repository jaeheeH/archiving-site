# 작품 탐색 분류

2026-10-13 현재 127점의 초기 분류를 `research/art-collection/taxonomy.json`에 정리했다. 기존 작품·작가 식별자, 원문 제작 시기, 재료, 이미지, 권리 표시와 작가 연결은 변경하지 않는다.

## 분류 기준

| 구분 | 현재 사용하는 값 |
| --- | --- |
| 시대 | 근세 · 15–18세기, 근대 · 19세기, 20세기, 한국 · 조선, 일본 · 에도 |
| 사조·양식 | 르네상스, 바로크, 신고전주의, 낭만주의, 사실주의, 인상주의, 후기인상주의, 상징주의, 우키요에, 린파 |
| 작품 종류 | 회화, 판화, 드로잉; 조각은 관리자에서 선택할 수 있으나 현재 수집 작품이 없어 공개 필터에서 생략 |
| 주제 | 풍경, 실내, 인물, 정물, 일상, 동식물, 종교·신화, 역사·사건, 음악·공연, 꿈·상상 |

시대는 탐색용 구간이다. 서양 작품의 근세/근대 구간을 조선·에도 작품에 그대로 적용하지 않는다. `1900s`처럼 세기를 가리키지만 특정 왕조를 확정할 수 없는 표기는 20세기로만 정리한다. 원문 연대가 두 구간에 걸치면 두 시대를 모두 선택한다. 세잔의 약 1895–1900년 작품은 근대와 20세기 양쪽에서 찾을 수 있다.

사조는 작품별로 검토한 편집 분류이며 작가의 모든 작품에 자동 상속하지 않는다. 초기 르누아르의 1864년 초상, 마네 소장작, 함메르쇼이 작품 등 확정하기 어려운 사조는 비워둔다. 사조의 관습적인 전성기 밖에서 제작된 후기 작품도 확인한 양식·맥락에 따라 같은 사조로 탐색할 수 있다. 그래서 인상주의는 19세기뿐 아니라 20세기에서도 선택할 수 있다.

작품 종류는 재료명과 별개다. 클리블랜드의 수채·파스텔 24점은 공식 API의 `type: Drawing`을 확인해 드로잉으로 정리했다. 상세 화면의 재료·기법 표기는 그대로 보존한다. 주제는 화면의 주요 소재와 소장처 해설에 근거한 복수 태그이며, 임의의 동의어를 입력하지 않고 정해진 값을 선택한다. 기존 `themes`는 큐레이션 주제로 보존한다.

각 작품의 `taxonomy.sources`에는 개별 소장품 출처와 필요한 사조 해설을 함께 기록한다. 시대·종류·주제는 개별 소장품 정보에, 사조·양식은 소장처 설명과 관련 미술사 자료에 근거해 편집 판단한 값이다. 기관이 모든 태그를 직접 부여했다고 표시하지 않는다.

주요 맥락 자료: [인상주의](https://www.metmuseum.org/essays/impressionism-art-and-modernity), [후기인상주의](https://www.metmuseum.org/essays/post-impressionism), [다비드와 신고전주의](https://www.metmuseum.org/es/essays/the-legacy-of-jacques-louis-david-1748-1825), [르네상스·바로크 초상](https://www.metmuseum.org/zh/essays/portraiture-in-renaissance-and-baroque-europe), [에도 린파](https://www.metmuseum.org/exhibitions/listings/2012/rinpa-aesthetic), [히로시게와 우키요에](https://www.metmuseum.org/art/collection/search/55433). 모두 공식 미술관 자료이며 작품별 출처는 분류 파일을 따른다.

## 저장과 편집

초기 분류 파일을 카탈로그 읽기에 합쳐 DB가 있는 환경과 초기 데이터 환경에서 같은 분류를 제공한다. 기존 DB 레코드를 일괄 수정하거나 스키마를 추가하지 않는다. 관리자가 작품을 저장하면 선택한 `taxonomy`가 기존 `artworks.data` 안에 저장되며, DB에 저장된 분류가 초기 파일보다 우선한다. 빈 분류를 명시적으로 저장하면 초기 태그가 다시 붙지 않는다. 예전 클라이언트가 `taxonomy`를 생략해 저장해도 이미 저장된 분류는 보존된다.

관리자 편집에는 시대·사조·종류·복수 주제와 출처를 제공한다. API는 허용한 분류 값, 중복 선택, 사조와 시대의 관계, HTTPS 출처를 검증한다. 분류를 붙이면 출처가 한 곳 이상 필요하다. 새 작품은 근거를 확인한 뒤 관리자에서 분류하며, 초기 파일에 없는 작품을 이름·재료·연대로 자동 추정하지 않는다.

## 탐색 동작

- `/art`와 `/artists`에서 시대 → 관련 사조 선택, 종류, 주제, 소장처를 조합한다. 아트에는 작가 선택도 제공한다.
- 선택 필터와 주제 체크는 즉시 적용하며 스크롤 위치를 유지한다. 시대를 바꾸면 사조 선택을 초기화한다. 검색어는 Enter 또는 검색 버튼으로 적용한다.
- 필터는 항목별 드롭다운으로 묶어 한 줄에 보여주며, 선택한 조건은 아래에서 개별 해제할 수 있다. 주제는 복수 선택, 나머지 항목은 단일 선택이다. 바깥 클릭·Escape·다른 항목 열기로 메뉴를 닫는다.
- 서로 다른 필터 그룹은 모두 만족해야 한다. 여러 주제는 그중 하나라도 포함하면 된다.
- 작가 필터는 한 작품이 선택한 조건을 모두 만족하는지 확인한다. 19세기 풍경과 20세기 실내화를 가진 작가가 있다는 이유만으로 `20세기 + 풍경`에 노출하지 않는다.
- 작가 목록의 이미지는 선택 조건을 만족하는 작품에서 고르며 일치 작품 수와 전체 수를 구분한다. 상세 페이지의 분류는 현재 수집 작품에서 모아 보여준다.
- 카드 주제와 상세의 분류를 누르면 해당 작품 목록으로 이동한다. 작가 카드·상세의 분류 링크는 그 작가 조건도 유지한다.
- 목록은 기존 masonry, 제목 옆 북마크를 유지한다. 필터 상태는 GET 주소에 남고, 조건 초기화와 브라우저 뒤로가기를 지원한다. 주제와 사조는 통합 검색 및 저장 자료 검색에도 포함한다.
- 필터 주소는 `noindex`이며 기본 목록 주소는 기존 대표 주소를 유지한다.
