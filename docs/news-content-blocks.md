# 뉴스 본문 이미지·표·코드

뉴스 편집 화면에서 각 본문의 **이 섹션 다음에 넣기**로 추가합니다. 기존 텍스트 원고와 페이지 구성은 유지합니다.

- 이미지: 파일 업로드 후 이미지 설명과 출처·크레딧을 입력합니다. 아래 설명은 선택입니다. 기존 대표 이미지와 별개입니다.
- 표: 첫 줄은 열 제목, 이후는 데이터입니다. 스프레드시트에서 복사하거나 탭으로 열을 구분해 붙여넣습니다. 최대 8열·40행입니다.
- 코드: 제목·언어·코드를 입력합니다. 공개 화면에서는 접고 펼치거나 복사할 수 있으며 코드를 실행하지 않습니다.

한 섹션에 최대 4개, 기사 전체에 최대 24개를 넣습니다. 같은 섹션 안에서는 위로·아래로 이동할 수 있고, 섹션을 제거하면 그 섹션의 첨부도 함께 제거합니다. 업로드한 저장소 파일은 삭제하지 않습니다.

데이터는 기존 `archb-news-v1` 콘텐츠의 선택 필드 `blocks`에 저장합니다. `afterSection`은 0부터 시작하는 섹션 위치입니다. 이전 클라이언트가 `blocks`를 보내지 않으면 저장된 첨부를 유지하고, 빈 배열을 보내면 연결을 제거합니다. 불완전한 첨부는 비공개 초안으로 저장할 수 있으며 공개할 때 검증합니다. 이미지 URL은 기존 뉴스 업로드 저장소만 허용합니다.

예제 원고: `content/news/container-query-comparison.json`.

검증:

```powershell
npx tsx scripts/check-news-content-blocks.mjs
node scripts/check-news-thumbnails.mjs
npx tsx scripts/check-news-reading.mjs
```
